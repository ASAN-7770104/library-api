# REST API библиотеки книг

[English](README.md) · **Русский**

REST API для управления книгами на Express: проверка данных, свои промежуточные обработчики, фильтры и сортировка.

## Запуск

```bash
npm install
npm start
```

Сервер работает на <http://localhost:3000>. Другой порт задаётся переменной `PORT`. Тесты: `npm test`.

## Книга

| Поле | Тип | Правила |
|---|---|---|
| `id` | строка | создаёт сервер |
| `title` | строка | обязательно, 2–100 знаков |
| `author` | строка | обязательно, 2–60 знаков |
| `year` | число | обязательно, целое от 1450 до текущего года |
| `genre` | строка | обязательно |
| `available` | логическое | по желанию, по умолчанию `true` |
| `createdAt` | строка | дата ISO, ставит сервер |

## Адреса

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/books` | все книги, есть фильтры и сортировка |
| GET | `/api/books/stats` | всего, доступно и количество по жанрам |
| GET | `/api/books/:id` | одна книга |
| POST | `/api/books` | создать |
| PUT | `/api/books/:id` | заменить все поля |
| PATCH | `/api/books/:id` | изменить только переданные поля |
| DELETE | `/api/books/:id` | удалить |

Фильтры: `?genre=`, `?author=`, `?available=true`; сортировка: `?sort=year`, `?sort=-year`, `?sort=title`.

Примеры запросов и ответов смотрите в [английской версии](README.md) и в коллекции Postman.
